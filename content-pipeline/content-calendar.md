# Faraway Folio, posting plan

## Posting rhythm
- Instagram: 1 carousel post every 2-3 days (4 images per post, one theme), 2-3 Stories/day repurposing the same set
- Facebook: same carousel/multi-photo post, cross-posted same day
- X: retired 2026-09-14 (API now pay-per-use by default, media upload blocked without paid tier) — not in active use

## Post themes (each = 4 images, one carousel/multi-photo post)
See `prompts.json` for the exact prompts and captions. Currently:
1. **slow-mornings** — balcony, hotel room, poolside, rooftop view (pick: the Weekender Case)
2. **on-the-move** — cafe table, train platform, passport holder, airport lounge (pick: the Passport Folio)
3. **market-finds** — market street, bag handle, folded linen, cobblestone street (pick: the Linen Travel Set)

Keep a consistent color grade (warm neutrals, muted golds, soft contrast) across all of these — the aesthetic consistency is what makes an AI-content account read as a "brand" rather than random images.

## Caption style
Hand-written per post, not templated (a rigid "product + arrow + link in bio" formula read as bot-like). Each caption: one evocative line, a short second beat that ties in the pick naturally, then a plain "More on the site, link's in the bio" line. See `prompts.json` for exact text.

## Monetization sequencing (fastest to slowest)
1. **Digital product (fastest, no approval needed):** a printable wall-art / wallpaper bundle sold via Gumroad — this is the actual fastest lever and, as of 2026-09-14, still not built despite being identified as the priority from day one. See `MONETIZATION.md` for the concrete plan and current status.
2. **Amazon Associates:** apply once the site has real traffic — approval typically needs 3 qualifying sales within 180 days, so apply early but don't expect income here immediately.
3. **LTK (LikeToKnow.it) / ShopMy:** apply once IG has consistent posting history.
4. **Direct brand affiliate links** (luggage brands, travel gear) once there's engagement data to show them.
